# Moneyball FPL-liga

Dashboard for en privat FPL-liga med ni deltakere: tabell, rundeoppsummeringer, chips og en matrise over alle runder.

- `index.html` er den ferdige siden (GitHub Pages). Bildene ligger i `img.js`, `img2.js` og `img3.js`.
- `data/` har rundedata og chipdata som CSV.
- `src/` har kildeteksten fra Artifact-versjonen og oppsummeringstekstene.

Vis siden: Settings → Pages → Deploy from a branch → `main` / root.

Live: https://fredrikn89-create.github.io/Moneyball/
